Excel Stopping Distance Curve Fit

Interactive Excel-based measurement analysis for vehicle stopping distances. The tool filters road-surface data, fits a polynomial curve, and estimates stopping distance at custom speeds.

Back to ProjectsGitHub repository

Interactive analysis

The primary assignment case is wet road conditions. Other surfaces are included as an interactive extension.

SpeedReactionBrakingStopping

Method

Stopping distance is calculated as reaction distance plus braking distance. A second-degree polynomial is fitted to the selected road surface, then used for extrapolation. The 150 km/h result is outside the original 30–120 km/h measurement range, so it should be treated as an estimate.
