The tool calculates stopping distance from reaction and braking distance, then fits a polynomial curve to the selected road surface.

Overview

The project uses vehicle stopping-distance measurements for dry, wet, snowy, and icy road surfaces.

Engineering problem

Stopping distance grows nonlinearly with speed, so curve fitting helps estimate values beyond measured data.
